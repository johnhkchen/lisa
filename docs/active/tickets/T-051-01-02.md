## Context

`just check` is the one command agents are taught as the local bar: WASM `cargo check` + `cargo test --workspace`. CI additionally fails on clippy warnings — so a tree can pass `just check` and still bounce, which is exactly what happened to commit 53481ac (unused import, green local gate, red CI). Add the same clippy invocation CI uses (workspace, all targets, warnings denied) to the `check` recipe so a green `just check` is a commitment CI honors. Keep the recipe's runtime reasonable and its output legible; the goal is one honest gate, not a longer ritual.

_Advances: P2 for the local gate — green means green, everywhere._

## Acceptance Criteria

- [ ] `just check` fails on a tree with an introduced clippy warning (demonstrate the negative fixture in progress notes, then revert it) and passes on the current tree.
- [ ] The clippy flags match what CI enforces — cite the CI workflow lines in progress notes so drift is visible next time either side changes.
- [ ] CLAUDE.md's description of `just check` ("WASM check + tests") is updated to name clippy too; no other CLAUDE.md edits.
