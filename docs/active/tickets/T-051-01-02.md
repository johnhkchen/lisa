## Context

`just check` is the one command agents are taught as the local bar: WASM `cargo check` + `cargo test --workspace`. CI additionally fails on clippy warnings and rustfmt drift — so a tree can pass `just check` and still bounce, which happened twice on the 0.4.4 train: commit 53481ac (unused import, green local gate, red CI) and the rc.8 fix commit ce1058e (hand-edited layout, `cargo fmt --check` red while every local test gate was green). Add the same clippy invocation CI uses (workspace, all targets, warnings denied) and `cargo fmt --all -- --check` to the `check` recipe so a green `just check` is a commitment CI honors. Keep the recipe's runtime reasonable and its output legible; the goal is one honest gate, not a longer ritual.

_Advances: P2 for the local gate — green means green, everywhere._

## Acceptance Criteria

- [ ] `just check` fails on a tree with an introduced clippy warning, and separately on a tree with a formatting drift (demonstrate both negative fixtures in progress notes, then revert them); passes on the current tree.
- [ ] The clippy and fmt invocations match what CI enforces — cite the CI workflow lines in progress notes so drift is visible next time either side changes.
- [ ] CLAUDE.md's description of `just check` ("WASM check + tests") is updated to name clippy too; no other CLAUDE.md edits.
