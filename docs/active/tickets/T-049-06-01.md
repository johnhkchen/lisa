## Context

The severity dial's mechanism. Add the third disposition class to the fail-closed parser (crates/lisa-core/src/disposition.rs) and the completion path (crates/lisa-core/src/completion.rs): a **note** disposition — shape carrying the disputed criterion quoted verbatim, the recorded evidence cited by path, and a plain one-sentence summary — completes and seals exactly like a pass (same reconcile eligibility, same seal tier, same atomicity), additionally recording the note in the completion journal row and provenance. The class is only expressible for criteria-versus-evidence disputes: the schema has no free-form work-complaint field, and a note missing the criterion quote or the evidence citation parses Invalid — fail-closed exactly as today. Bare `pass` stays strict (pass-with-reason remains Invalid); `block` semantics are untouched. Motivating incident: E-046's closing ticket was blocked over a 75 MiB paperwork-versus-measurement gap that deserved a sealed completion and one queue line, not a stopped line (field disposition preserved in docs/active/work/T-046-06-03/operator-note-2026-07-17.md).

_Advances: a reviewer with a criteria dispute has a move that keeps the line flowing — severity becomes expressible, and the fail-closed floor never drops._

## Acceptance Criteria

- [ ] Parser tests: a well-formed note parses to its own variant; missing criterion quote, missing evidence citation, pass-with-reason, and unknown shapes all parse Invalid; existing pass/block fixtures unchanged.
- [ ] Completion tests: a note disposition reconciles to completion and seals identically to a pass on both seal tiers, dependents become schedulable, and the journal/ledger rows carry the note record; the T-046-06-03 field block re-expressed as a note is the fixture and produces one sealed ticket, zero parks.
