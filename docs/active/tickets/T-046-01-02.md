## Context

`lisa doctor` today only echoes `zellij --version` as an opaque string (crates/lisa-cli/src/doctor.rs:77-86), and a below-floor host dies silently at runtime: the plugin renders its dashboard but every pane write is an undecodable protobuf on the old host, so Lisa looks alive and drives nothing. Wire the T-046-01-01 range check into `lisa doctor` and `lisa loop` preflight: an out-of-range or unparseable system Zellij becomes a refusal that names the detected version, the required floor, and the remedy. Remedy wording points at Zellij's prebuilt static binaries until the managed runtime (S-046-02) exists, then names that.

_Advances: refusal-not-silence — failure stays visible and actionable instead of being mislabeled as a working session._
