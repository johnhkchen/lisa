## Context

The orphaned-block fix. On 2026-07-17 a reviewer blocked T-046-06-03 at 08:15 and the session ended before the next poll; the park policy (crates/lisa-plugin/src/lib.rs, apply_review_block_policy) requires a Running review thread holding the current lease, so it never fired. Result: durable disk state said blocked, but the ticket stayed `phase: review, status: open` — absent from Waiting-on-you (crates/lisa-core/src/parking.rs requires `status: blocked`), yet schedulable, so the next loop re-seated a reviewer to re-derive a verdict already on disk while a ready ticket waited seatless. Make parking level-triggered, the way completion reconciliation already is: at plugin load and every poll, a review-phase ticket whose current-generation review-disposition.json parses to Block (structured or the legacy operator+unstructured fallback) parks — status written, provenance park row, seat released if held — regardless of whether the writing thread's lease survives. And respect durable verdicts on the scheduling side: a schedulable pass must not spawn a review thread for a ticket whose current-generation Block verdict is already on disk; parking, not re-review, is the response. Unparked tickets (operator reopen, `lisa unblock`, world recheck) re-review normally — that path is untouched.

_Advances: an orphaned block becomes an unrepresentable state — every block reaches its parked, seat-free, visible form no matter when its session died, and no seat is ever spent re-deriving a verdict the board already holds._

## Acceptance Criteria

- [ ] Fixture tests: block disposition on disk + no live thread → plugin load parks the ticket (status, provenance row, Waiting-on-you entry) with no review thread spawned; the same holds when the disposition appears mid-run after its thread is gone; live-thread parking behavior and all existing E-048 tests unchanged.
- [ ] Scheduling tests: a review-phase ticket with a durable current-generation Block verdict is never seated; after unpark it seats and re-reviews normally; a stale prior-generation disposition does not park a fresh attempt.
