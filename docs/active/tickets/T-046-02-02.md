## Context

Managed mode acquires its runtime: download the pinned **no-web static-musl** Zellij (x86_64/aarch64, matching the compiled zellij-tile minor) from Zellij's GitHub releases, verify against a sha256 **baked into the Lisa binary at release time** (never fetched), and unpack atomically (temp + rename) into the per-version runtime dir so upgrades never clobber. Failure is bounded and named: checksum mismatch or offline-with-no-cache produces one error printing the exact tarball URL and expected sha256 — no retry loops, no silent fallback to an unvetted system binary. A cached runtime means zero network on subsequent runs.

_Advances: recovery is bounded, observable, and ends in a named actionable state; the runtime's provenance is verifiable rather than trusted._

## Acceptance Criteria

- [ ] Integration tests against a local fixture server cover: successful fetch+verify; checksum mismatch (named error, no partial install); interrupted download (no torn runtime dir); offline with no cache (single named error with URL + sha256, no retries).
- [ ] A second `lisa loop` with the runtime already cached performs zero network calls, observably in the test.
