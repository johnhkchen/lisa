## Context

**Read `S-071-01` first, and do `T-071-01-01` first.**

The operator, 2026-08-15:

> *"prepare to support the same for codex."*

And the reason, which is the part worth carrying into the design:

> *"the codex / openai subscription option is still available, so we want to have
> both an efficiency gear and a $400 a month double-quad-max-plan gear once we
> hammer out this orchestration system's details."*

**Two gears, not two vendors.** The point is not that codex is a fallback; it is
that the desk should be able to change what it is spending without changing how
it works.

## What is already true

- `agent.client` chooses between `claude` and `codex` and detects what is on
  PATH.
- `codex_args` exists and is tested — `["--model", "o4"]` appears in
  `agent_exec.rs`'s own tests.
- `capture_usage.rs` already parses codex rollouts on a separate branch,
  selected by `LISA_AGENT_CLIENT=codex`, reading cumulative
  `event_msg/token_count` records where the last one wins.

So codex is not a stranger here. What is missing is that `T-071-01-01`'s two
words have to mean something in a client whose flags are its own.

## Acceptance Criteria

- **`model` and `effort` map onto codex's actual flags, or are refused for
  codex with a reason.** Do not invent an equivalence. If codex has no notion of
  effort, a config that sets it for a codex board should say so when it is read.
- **The config shape does not have `claude` in its name.** Whatever
  `T-071-01-01` chose, this ticket is the check that it was not a claude-shaped
  hole.
- **A board can be moved between clients without rewriting its per-pane
  settings**, or the cost of doing so is stated. That is what *"two gears"*
  means in practice.
- **The capture ledger stays comparable across clients.** `T-071-01-02` adds a
  model to the record; a codex record and a claude record should be countable in
  the same reading, because the whole reason for switching gears is to compare
  what they cost.
- Reproduce it: set a board to codex with a per-pane model, run it, and have the
  ledger say what ran.

## Notes

- **`phase: design` on purpose.** Nothing here should be built until
  `T-071-01-01` has settled the shape, and the useful work of this ticket is
  saying whether that shape survives contact with a second client.
- Worth deciding in review: whether *effort* is a claude word this desk should
  keep as a claude word, or a desk-level idea — *how hard to think about this* —
  that each client expresses however it can. The second is more useful and more
  work, and it is the one that makes two gears real.
- The desk runs codex nowhere today. This is preparation, and preparation that
  is never exercised rots — say what would exercise it.
