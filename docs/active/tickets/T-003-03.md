## Context

When a session exits or a ticket reaches `done`, unblock dependents and schedule
the next wave.

## Acceptance Criteria

- On `CommandPaneExited` with exit code 0: if ticket was in implement phase, mark as done
- On non-zero exit: mark thread as failed, log error, leave ticket phase unchanged for retry
- After any ticket state change: rebuild DAG, call `schedule()` for newly-ready tickets
- Loop terminates cleanly when all tickets are done (no more ready tickets)
