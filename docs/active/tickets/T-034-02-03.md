## Context

Bind liveness to attempt identity and make artifact admission attributable to the current lease, so a resumed old pane cannot keep a replacement alive or publish shared artifacts that advance it. Shared-path existence alone is not sufficient attribution.

_Advances: P1 — Preserve the repository; P2 — State means what it says; E-034_

## Acceptance Criteria

- [ ] Tests feed a stale-attempt heartbeat and have stale/current attempts produce the same logical artifact: stale liveness does not keep the replacement alive, stale output cannot appear as current or advance phase, and only current-lease publication is admitted. The chosen design uses attempt-scoped staging/publication or proves an equivalent enforceable boundary.
