## Context

Two emitters turn one fact into a column of lines. First: `schedule_ready_tickets` logs Info "Skipping {}: thread already exists" (crates/lisa-plugin/src/lib.rs ~4934) every time it declines to double-spawn — and it runs on nearly every event (permission grant ~8605, PaneUpdate ~8623, the timer poll, three RunCommandResult arms ~8658), so a single healthy in-flight thread re-announces itself once per pass, indefinitely. A recurring no-op is not operator news: take it out of the feed — and since the Shift+D dump's only event record is this very ring (`format_snapshot`'s activity section, ~8098), give the demoted fact its own berth: a compact last-scheduling-pass section in the dump, or a debug ring the feed never projects (design decides the vehicle; demotion, not erasure). Second: one phase transition logs both `PhaseCompleted { current }` and `TicketPhaseChanged { new }` (emit pairs at ~5548, ~6086, ~6192, ~3115), and the UI projection maps *both* variants to "completed" lines (~9080–9091) — "completed {old}", then "completed {new}" — so every transition prints twice, consecutive transitions mint verbatim-identical lines (entering Design prints the same sentence leaving it will), a transition observed by two of the three advance detectors (artifact, idle, completion) doubles the pair, and `ThreadExited` mints a third "completed Done" shape (~9076): the stuttering column in the field screenshot. Pick the single-line shape (one line naming the transition; the exact sentence is design's call), enforce it across all three detector paths, and make the projection incapable of minting two lines from one transition.

_Advances: one fact, one line — the feed compresses a morning instead of transcribing the scheduler's pulse (P4)._

## Acceptance Criteria

- [ ] A scheduling pass over a board whose ready candidates all have live threads appends zero feed entries (unit test counts the log before and after the pass).
- [ ] One phase transition produces exactly one feed line — verified separately for the artifact path, the idle path, and the completion path, including a fixture where two detectors observe the same transition.
- [ ] After demotion the state dump still answers "why didn't X spawn?" through its own section or debug ring, not the activity ring — shown in progress notes (P2: the fact survives; only the feed stops carrying it).
- [ ] Negative fixture: two different tickets completing the same phase still yield two distinct lines — nothing ever merges across facts.
- [ ] `just check` green (fmt, clippy, WASM check, workspace tests).
