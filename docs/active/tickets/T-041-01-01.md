## Context

Establish the settled typed vocabulary of the completion aggregate — lifecycle state enum, event enum, identity newtypes, and non-boolean outcome types — so illegal completion states are unrepresentable.

_Advances: P2 — State means what it says; P1 — Preserve the repository_

## Acceptance Criteria

- [ ] lisa-core exposes a pure `completion` module (re-exported in lib.rs) whose `CompletionState` (Eligible/Requested/CommandInFlight{correlation}/Rejected{reason,retryability}/Confirmed), `CompletionEvent`, attempt/completion identity newtypes + correlation id, `EffectCommand`, `Transition`, and `CompletionRejection` types compile under `cargo test --workspace`; a CommandInFlight state cannot be constructed without a correlation id, and each rejection is a distinct non-boolean variant (already-pending, stale-lease, disposition-blocked, dependency-blocked, launch-failed). `thiserror` is a new lisa-core dependency used only for rejection Display/source, no Zellij/WASM import.
