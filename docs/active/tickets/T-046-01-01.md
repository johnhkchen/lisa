## Context

Give lisa-core a comparable Zellij version type and one declared supported range: floor 0.43.0, matching the pinned zellij-tile minor (crates/lisa-plugin/Cargo.toml:14). The hard API floor is 0.41.0 — `write_chars_to_pane_id`/`write_to_pane_id` cannot be decoded by 0.40 hosts — but we enforce the tested floor, not the theoretical one; record that distinction in code comments. The range constant is the single source of truth: bumping the zellij-tile pin must have one obvious edit site that keeps floor, pin, and docs together.

_Advances: "supported" becomes a checkable claim instead of vibes — published state matches durable reality; smallest contract, no scheduler change._

## Acceptance Criteria

- [ ] Unit tests parse real-world `zellij --version` outputs (stable release, prerelease, garbage) into in-range / below-floor / unparseable verdicts; unparseable is never treated as a pass.
- [ ] The supported-range constant lives in one place in lisa-core with the zellij-tile pin rationale and the 0.41.0 hard-floor note commented beside it.
