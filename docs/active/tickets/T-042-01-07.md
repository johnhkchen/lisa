## Context

Stop Review timeout from telling an agent to rewrite an artifact Lisa has already admitted. In all three Arcade incidents the review existed; the real problem was completion transaction failure, but the timeout path emitted the generic missing-review prompt and hid that failure.

_Advances: P4 — Operable at a glance; P2 — State means what it says_

## Acceptance Criteria

- [ ] Review timeout emits the finish-up prompt only when the current attempt's Review artifact is genuinely absent; when review exists and completion is pending, confirmed, retryable, or action-required, it emits no prompt and preserves/renders the correlated completion state. Tests cover missing review, admitted review pending, nested-path launch rejection, and retryable command failure.
