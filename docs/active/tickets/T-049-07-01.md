## Context

The first responder. When a review block parks operator-owned (E-048 machinery, level-triggered per T-049-05-01), run a bounded agent triage pass that reads the block, the ticket, and the cited evidence, and attaches a **proposal** to the parked state: one plain sentence naming what happened, a recommended action, and the prepared commands or file edits the operator would approve. Waiting-on-you surfaces render the proposal ahead of the raw reason (crates/lisa-plugin/src/lib.rs park flow, crates/lisa-core/src/parking.rs projection, status/ui rendering). The template ritual is the 2026-07-17 manual resolution of T-046-06-03: agent reads the jargon, checks the evidence, discovers the remedy is a two-sentence amendment, hands the operator one decision. Hard rules: triage is **fail-open** — error, timeout, or disabled config yields the unmodified S-049-05 park with its plain ask, and triage may never delay, gate, or alter the park itself; triage runs on configured agent seats within visible provenance-recorded bounds (no hidden spend); proposals are advice — applying one is always an explicit operator action recorded as such, and a wrong proposal costs one dismissal. Triage proposes; only the operator disposes.

_Advances: a cord pull summons a team lead before it summons the human — what reaches Waiting on you is a decision with prepared steps, never an excavation._
