## Context

nfpm (zero-dependency; repackages the tarballs cargo-dist already builds; wired via dist `extra-artifacts` plus a custom publish job) produces two debs per release for amd64 and arm64: `lisa` (the CLI at /usr/bin/lisa) and the companion `lisa-runtime-zellij` (the same pinned no-web static-musl Zellij the managed fetch uses, at /usr/libexec/lisa/zellij — the Jellyfin `jellyfin-ffmpeg` model), with `lisa` Recommends-ing the companion. The runtime resolver learns to prefer /usr/libexec/lisa/zellij when present, making an apt install fully offline-complete at loop time. cargo-dist upstream has no deb support and no plans (issue #76), so this is our own step, not a wait.

_Advances: Debian's native install motion works end-to-end with the runtime included — no first-run download, no PATH surprises._

## Acceptance Criteria

- [ ] Release CI produces all four debs from the same tag as the tarballs; local `apt install ./lisa*.deb ./lisa-runtime-zellij*.deb` on a clean bookworm container yields `lisa doctor` exit 0 with the runtime resolved from /usr/libexec/lisa/ and zero network at loop time.
- [ ] The resolver's /usr/libexec/lisa/zellij preference is covered by a unit test and reported by doctor as its own provenance mode.
