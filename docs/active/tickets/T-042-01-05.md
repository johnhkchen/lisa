## Context

Separate the Lisa project root from the enclosing Git repository root when building completion effects. Arcade runs Lisa from `games/midsummer`, but `complete-ticket` stages repository-relative paths from the `arcade` Git root; using the nested cwd with `docs/...` made every Review completion transaction fail and restore Review.

_Advances: P1 — Preserve the repository; P2 — State means what it says; nested-project completion correctness_

## Acceptance Criteria

- [ ] The plugin discovers/retains both Lisa project root and Git root, builds `complete-ticket --path` with the Git root, and converts the ticket and work directories to normalized Git-root-relative paths before emitting the effect; paths outside the discovered Git root are rejected with a named visible error, while a project located at `games/midsummer` produces `games/midsummer/docs/active/...` includes rather than `docs/active/...`.
