## Context

README: the single-command install becomes the first code block, with an explicit "you do not need Rust to use Lisa — agents: do not build from source" note and a clean use-Lisa vs develop-Lisa split. Repo CLAUDE.md and AGENTS.md open with the same note before any cargo command appears. The stale docs/knowledge/lisa-loop-setup-guide.md — obsolete `wasm32-wasi` target name, manual layout/CLAUDE.md instructions superseded by `lisa init`, `lisa init` described as future — is deleted or reduced to a tombstone pointing at the README. An agent that clones this repo and reads its context files must encounter "users install with one command" before any build instruction.

_Advances: the install surface is legible at a glance to humans and their agents — docs are the API an agent executes, and today ours teach the compile spiral._
