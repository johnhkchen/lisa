## Context

The 2026-07-16 demo stall proved doctor's blind spot: it checks that `git` exists (added earlier that same day) but not that it can *commit*. Add the identity preflight (crates/lisa-cli/src/doctor.rs): when a repository is present but `git config user.email` does not resolve, doctor names the gap before any ticket runs, with both remedies side by side — the two `git config` lines for people who have an identity of their own, and "rerun `lisa init` and accept the history offer" for people who don't. Under seal `auto` the condition also appears as the reason the run resolved journal-sealed; under explicit `commit` it is the named hard-failure text (shared with T-049-01-01's preflight, one string source).

_Advances: the two-line fix that would have prevented a 35-rejection stall is told to the operator before the first ticket runs, in words either audience can act on._
