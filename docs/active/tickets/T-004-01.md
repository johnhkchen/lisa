## Context

Enrich the thread/session tracking to support lifecycle monitoring.

## Acceptance Criteria

- `Thread` extended with `last_phase_change: SystemTime` to track time-in-phase
- Health status enum: `Healthy | Stuck | Failed` with configurable timeout threshold
- On each timer tick, evaluate health: time-in-phase exceeds threshold with no new artifact → `Stuck`
- `is_attention_needed()` on Thread returns true if stuck, failed, or parked for review
