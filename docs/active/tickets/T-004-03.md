## Context

Surface failed and stuck sessions so the user knows something is wrong.

## Acceptance Criteria

- Failed sessions (non-zero exit): shown in attention banner with exit code and ticket ID
- Stuck sessions (no progress beyond timeout): warning with time since last activity
- Suggested actions: "restart session", "check logs", "mark as blocked"
- Activity log entries for health state changes
