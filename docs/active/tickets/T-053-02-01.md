## Context

The Operations screen currently *is* the memo pile: `render_waiting_on_you` (crates/lisa-plugin/src/ui.rs ~460) and `render_notes_for_you` (~494) print reason paragraphs, criterion quotes, and evidence paths inline, and `render_attention_banner` (~522) stacks Review-phase rows beneath them — the field screenshot shows a person greeted by codesign flags and `.appex` paths before any sentence says what is actually wanted. Build the Present preset: one collapsed card per pending decision, drawing on the same sources — `collect_parked_remedies` (parking.rs ~121), Review-phase tickets, `collect_notes` (lib.rs ~8804) — plus the class those sources miss: a Blocked ticket whose disposition is missing or unparseable is invisible to the remedy collector (parking.rs ~118) yet is exactly the ticket the no-review override serves, so it gets a card too, wearing the no-review-on-file framing. Collapsed card ≤3 lines: id + short title, age via T-052-01-01's formatter where a stamp exists (parked blocks carry an in-memory `parked_at` that resets with the plugin; notes carry no stamp at all, notes.rs ~163 — a card with no age source shows "—", never an invented number), the one-sentence ask the disposition schema already mandates (`ask` for blocks, `summary` for notes), and the recommended key. The selected card expands to the full staff work — reason, criterion quote, evidence citation, steps, check command — one keypress deep, never the default. Operations' three sections collapse to one-line pointers with counts ("5 waiting, 2 notes — [p]"); the paragraphs leave the default screen entirely. Empty desk: "Nothing needs you." Cards render fields the dispositions already carry — no new prose generation, no summarization pass; a jargony ask surfaces verbatim, as the disposition author's bug to fix upstream.

_Advances: the operator reads memos, not transcripts — every pending decision in three lines, details on request (P4)._
