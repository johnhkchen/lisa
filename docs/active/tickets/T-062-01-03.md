## Context

**Read `S-062-01` first.** Third in the same subject: what a running loop looks
like from outside.

The plugin pane's title, as the operator sees it right now:

```
file:/var/folders/kn/7f93dn8n1wb51m_jydvylncw0000gn/T/lisa-plugin-8fd16992c4a2b9fd.wasm
```

A temp path and a content hash. It is the widest, most constant strip of text on
a `lisa loop` screen, it is identical on every project, and it says nothing.

The operator's ask, and the reason is the useful part:

> *"can we make it act like a ticker for the lisa loop? movement and change helps
> direct user attention and this row is a constant across many projects."*

**Movement is the point, not information density.** A row that changes is a row
the eye returns to; a row that has said the same thing for an hour stops being
read. This desk runs three loops at once now, and the operator is not watching
any of them — they glance. A ticker is built for glancing.

## What it could carry

The plugin already holds all of this; none of it is a new read.

- which seats are working, and on what — `2/4 · T-004-03 · T-004-04`
- what just finished, briefly, so a completion is visible to someone who was not
  looking at the moment it happened
- how long the current attempts have been running
- the project, since the same row appears on every station

**Pick a small number and defend them.** The dashboard below already shows slots,
active, done and the DAG; a title bar that repeats it is a second copy that can
disagree. The title's advantage is that it is visible when the dashboard is
scrolled, in another view, or on a station being watched from across the room.

## What to be careful about

- **It must not become a load.** This is a title string; whatever produces it
  should be state the plugin already has, on a cadence a person can read — a
  second or two, not every event.
- **It must not flicker between two things faster than it can be read.** A ticker
  that alternates every 200ms is noise, and noise is worse than the wasm path
  because it also moves.
- **Length.** The title is truncated by the terminal and by whatever is above it;
  say what it looks like at 40 columns and at 200.

## Acceptance Criteria

- The plugin pane's title says what the loop is doing, and changes as that
  changes. Show it at three moments: idle, one seat working, and just after a
  ticket finished.
- **It reads at a glance from across a room.** State the cadence and what it
  looks like truncated. If two facts compete for the space, say which wins.
- Nothing in it is a second computation of something the dashboard shows. Name
  the state you read.
- No wasm path, no temp directory, no content hash. Those are build details and
  they are the only thing there today.
- Idle is not blank. A loop with nothing to do should say so — that is a fact the
  operator wants from across the room as much as any other.
- The cost is stated: how often it updates and what that costs when three loops
  are running on one machine.
