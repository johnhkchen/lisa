## Context

**Read `S-068-01` first.**

We found out the fleet had drifted by noticing it. Machines had been four weeks
behind for four weeks and nothing on any of them said so.

`lisa doctor` is the tool that should have said it. It already reports the version
of everything Lisa depends on — Zellij against `SUPPORTED_ZELLIJ_RANGE`, git,
`claude`, `codex`, the embedded plugin — and the README describes its job as naming
*"the exact command that settles each difference."* **The one version it does not
report is Lisa's own, and the one difference it cannot name is the one that made
this story.**

## Acceptance Criteria

- **`doctor` reports Lisa itself as a check**, in the same row shape as the others:
  the channel the machine is on, the version installed, and the version that channel
  currently resolves to.
- **A box that is behind its channel is a named, non-OK result, and the row carries
  the command that settles it** — `lisa upgrade`, or `lisa upgrade --channel <name>`
  when no channel is set. This is the existing `doctor` idiom, not a new one.
- **A box that is level with its channel is OK and quiet.** Drift reporting that
  cries every run gets ignored, and then it is not reporting anything.
- **An unset channel is reported as unset, not silently treated as stable.** It is
  the state every machine is in today and the one thing an operator most needs to
  see.
- **The check degrades honestly with no network.** It cannot resolve the channel
  offline; it says so and reports the installed version, rather than claiming the
  box is level.
- **`doctor --json` carries the same fields**, so the fleet is askable from a script
  and not only by reading terminal output on each box in turn.
- Cover it: a box behind its channel, a box level with it, a box with no channel
  set, and the offline case.

## Notes

- This is the ticket that makes the fleet *askable*. `T-068-01-01` lets a machine
  hold an intention; this one lets us find out whether the machine is keeping it.
- Keep it to reporting. No auto-upgrade inside `doctor` — `doctor` is a thing you
  run to learn what is true, and a diagnostic that changes the system it is
  diagnosing is the mistake this repository has already written up more than once.
- The Zellij check is the model to copy: it names the detected version, the
  supported range, and what to do about the gap, all in one row.
