## Context

`lisa --help` opens with "Lisa - DAG-driven concurrent task scheduling" (crates/lisa-cli/src/main.rs) — mechanism-first, purpose-absent. The 2026-07-16 tour probe (evidence in T-046-06-02's work dir and the chromebook-install-test run records) showed the consequence: an agent given only the installed surface concluded Lisa is a ticket-graph tool and wrote an entire landing page without once saying "coding agent." Rewrite the CLI's self-description wording layer: the top about line and help orientation lead with what Lisa is for — it runs coding agents (Claude Code / Codex) against a ticket board so the operator doesn't approve every step by hand — before any mechanism vocabulary; the `setup-guide` and `hooks-guide` preambles (crates/lisa-cli/src/setup_guide.rs) open the same way. Words only: E-044's completed help grouping, display order, and command separation must not change.

_Advances: an agent or newcomer reading nothing but --help learns why the tool exists before how it works; copy is plain kitchen-table English, verb-forward, no jargon._
