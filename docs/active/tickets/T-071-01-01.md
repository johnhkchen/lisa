## Context

**Read `S-071-01` first.**

`[agent].model` is one value for a whole board and defaults to `"opus"`. There is
no setting for effort at all. A board's four panes therefore run identically, on
the most expensive model, at whatever effort the client picks — while doing four
different kinds of work.

Both flags exist on the client already:

```
claude --model <model>     Model for the current session
claude --effort <level>    Effort level for the current session
```

## Acceptance Criteria

- **A pane can be given a model and an effort**, and a board can say it once for
  all panes. Say where that lives in `.lisa.toml` and what wins when both a
  board-wide and a per-pane value are set.
- **Silence still means the client's own default.** A pane nobody configured
  runs what a person typing `claude` in that directory would get.
  `[agent].model`'s description already promises this — *"Omit it to use
  whatever the agent runs by default"* — and it must stay true both for panes
  that are unconfigured and for a desk that sets neither key.
- **An unknown model or effort is refused when the config is read**, naming the
  file and the key, not at the moment a run tries to start four panes. This desk
  has spent two days on tools that fail at the far end of a long path.
- **`lisa doctor` says what each pane will run.** Four panes with three different
  models is a thing an operator has to be able to see without starting a run.
- **The argv is built the same way for both clients.** `codex_args` is the
  existing pattern; whatever this adds should be the shape codex can wear, since
  `T-071-01-03` is going to ask for exactly that.
- **A model that the account cannot use fails loudly on the first pane**, not
  silently on all four. Say what happens — a refused run is fine, a run that
  quietly falls back is not, because the ledger would then attribute the tokens
  to a model that never ran.
- Reproduce it: configure two panes with different models, start a run, and have
  each pane's client show the model it was told to use.

## Notes

- **Effort is the newer of the two words and worth pinning down.** Say which
  levels are accepted and what happens when the installed client does not know
  the flag — an older `claude` on another machine of the fleet is the ordinary
  case here, and the mini runs a different build than the laptop.
- The operator's mapping, for the worked example: *"Overseers and planners can be
  opus"*, and grinding work is Sonnet at medium. So the natural shape is a
  default for the board and an override for the pane, not four independent
  settings.
- Worth deciding in review: whether effort belongs beside model in `[agent]`, or
  whether panes deserve their own table. Four panes with two keys each is eight
  lines of config, and the desk has already noticed that **a field nobody writes
  is a field the reader cannot lean on**.
