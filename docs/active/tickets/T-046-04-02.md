## Context

Every failure string is a prompt injected into someone's agent, and today ours steer toward compiling: doctor's missing-Zellij hint leads with `cargo install zellij` (crates/lisa-cli/src/doctor.rs:82), and the `lisa loop` embedded-WASM error recommends `git clone … && just release` (loop_cmd.rs:90-96). Rewrite both to name the managed runtime / shell installer. Close the two doctor gaps found in the survey: no `git` check anywhere (absence surfaces as a raw OS error at loop time — add a check with an apt hint), and the build.rs empty-placeholder WASM trap (a `cargo build -p lisa-cli` without the plugin build yields a binary that passes doctor and dies at loop — doctor must detect the empty embed and say so).

_Advances: failure stays visible with a working next step — a weak agent following only our strings lands on the light path, never the compile spiral._

## Acceptance Criteria

- [ ] `rg 'cargo install zellij'` over the repo returns nothing; the loop embedded-WASM error names the shell installer; both strings are asserted in tests where they are produced.
- [ ] Doctor with `git` absent names the gap and the apt remedy; a binary carrying the empty placeholder WASM fails doctor with a named message instead of passing.
