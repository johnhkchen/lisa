## Context

Fold any typed event through a pure, total reducer that returns an explicit transition plus at most one effect command, or an exhaustive typed rejection — never a boolean, never a side effect.

_Advances: P2 — State means what it says; P1 — Preserve the repository_

## Acceptance Criteria

- [ ] A pure `reduce(state, event) -> Result<Transition, CompletionRejection>` exists with an exhaustive match (no catch-all that hides a state), launches nothing and mutates no external state, and per-transition unit tests assert each legal edge yields the expected single effect command and each illegal edge yields the correct named rejection; `cargo test --workspace` is green.
