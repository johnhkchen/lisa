## Context

Host the debs in a GPG-signed apt repository and document the channel. Default proposal is Cloudsmith's OSS tier (free ≥50GB storage / 200GB-month delivery, attribution required); the zero-cost fallback is a reprepro/aptly static repo on GitHub Pages (1GB site / 100GB-month soft limits, armored private key as an Actions secret). The choice between them is John's, decided in this ticket with the trade-offs presented. Publishing wires into release CI as a publish job; the README gains a Debian/Ubuntu section with the keyring + sources.list snippet using `signed-by` pinning. This is a vendor repo — Debian-archive inclusion is a non-goal (embedded-copy policy §4.13 is exactly what the companion package violates on purpose).

_Advances: Debian and Crostini users get updates through the motion they already understand — apt — with signature verification, not curl-and-hope._

## Acceptance Criteria

- [ ] On a clean bookworm container, following only the README section: add repo, `apt install lisa lisa-runtime-zellij`, `lisa doctor` exits 0; `apt upgrade` moves an older installed version forward cleanly.
- [ ] Repo metadata is GPG-signed, the client snippet uses signed-by keyring pinning, and key handling in CI is documented.
