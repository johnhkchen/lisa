## Context

Lisa currently requires building from source (`just build-cli`). For distribution as
a normal CLI tool, `cargo install lisa-cli` should work. This requires preparing the
crate metadata, ensuring the WASM build step works in the crates.io build
environment, and publishing.

## Objective

Prepare the lisa-cli crate for publishing to crates.io so users can install it with
`cargo install lisa-cli`.

## Acceptance Criteria

- [ ] `lisa-cli/Cargo.toml` has complete metadata: description, license, repository, homepage, keywords, categories
- [ ] `lisa-core/Cargo.toml` has complete metadata (published as dependency)
- [ ] `lisa-plugin/Cargo.toml` has `publish = false` (WASM plugin is embedded, not published separately)
- [ ] build.rs works when WASM isn't pre-built (empty placeholder, with clear error in `lisa loop`)
- [ ] `cargo publish --dry-run -p lisa-core` succeeds
- [ ] `cargo publish --dry-run -p lisa-cli` succeeds
- [ ] README.md at workspace root with install instructions, quick start, and link to docs
- [ ] License file present (choose license — MIT or Apache-2.0 or dual)
- [ ] `cargo install --path crates/lisa-cli` works end-to-end on a clean build
