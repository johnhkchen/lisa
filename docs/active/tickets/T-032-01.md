## Context

Coding pane names are currently incidental side effects of the foreground
client. Claude commonly shows a shortened fragment of the ticket prompt, such
as `Complete T-029-01 workflow phases through review`; Codex commonly shows only
`lisa`. With four concurrent panes, neither form gives the operator a consistent
view of assignment or availability.

Zellij 0.43 exposes pane-renaming commands to plugins, and lisa already knows
the terminal pane ID, parsed ticket ID/title, resolved agent route, resident
session provider, and slot lifecycle. Use that scheduler-owned state to keep
the coding pane title accurate. This ticket follows E-002 because completion
and slot release are being made transactional there; the pane must not display
`idle` before the completion commit succeeds.

## Acceptance Criteria

- Lisa defines one deterministic pane-name formatter used by every provider and
  lifecycle path.
- While assigned, a terminal pane name includes the actual resolved agent
  (`claude` or `codex`), ticket ID, and the ticket's parsed frontmatter title.
- The name is set before or with a fresh launch, updated for same-provider pane
  reuse, and updated when a pane switches providers. A stale name from the
  previous ticket is never visible once the next prompt is submitted.
- After successful ticket completion and slot release, a pane retaining a
  reusable session is named `<resident-agent> · idle`; an empty shell/no-session
  slot is named `lisa · idle`.
- Commit failure, blocked completion, awaiting-human state, timeout recovery,
  and other non-release paths do not falsely rename an assigned pane to idle.
- The displayed provider reflects the actual resolved route when a requested
  route is overridden, substituted, or falls back.
- Ticket-title input is sanitized for control characters and bounded to a
  documented maximum display length. Truncation preserves the complete agent
  and ticket ID before shortening the human title.
- Repeated scheduler polls do not spam redundant rename operations; lisa tracks
  or compares the last applied name.
- Unit tests cover formatting, sanitization, truncation, and actual-vs-requested
  routing. Lifecycle tests cover fresh launch, same-provider reuse,
  cross-provider switch, successful release, failed completion, and an idle
  slot without a session.
- A live mixed Claude/Codex validation confirms Zellij displays the expected
  names through assignment → completion → idle → reassignment, with evidence
  recorded in the ticket review artifact.
- Focused plugin tests, the workspace test suite, the WASM release build, and
  plugin Clippy pass.

## Notes

- Use Zellij's pane rename API rather than shell escape sequences or provider
  prompt text, so foreground-process behavior cannot change the contract.
- Keep the title useful in a narrow tab bar. The ID and agent are the stable
  scan keys; the frontmatter title supplies human meaning.
- The canonical `<ticket-id>.md` filename lets Vend attach later epics with
  `--after T-032-01` while lisa continues to use frontmatter as its authority.
