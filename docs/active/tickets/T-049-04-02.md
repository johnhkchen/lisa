## Context

Three closers for the incident, all in crates/lisa-cli/src/commit_transaction.rs territory. Lock hygiene: the 2026-07-16 stall left `.lisa-commit.lock` in the project root — the commit transaction must release its lock on every failure path, and a stale lock from a dead process must be detected and named (age + absent holder) rather than compounding a stall; a live holder is respected. Empty-history discovery: the journal's actual fatal step — `discover_completion_commit`'s `git log --grep` exits 128 on a branch with no commits and is propagated as fatal via `?` — must treat empty history as `Ok(None)` ("no prior completion"), so the lookup can never fail a repo for being new. Field replay: build the regression from the preserved journal (docs/active/work/T-046-06-03/cbt-0716-211915-variant-xdg/demo-completion-journal.jsonl) — reconstruct the field environment (unborn branch, no identity) and assert that under the new policy the same situation produces exactly one bounded retry sequence, one park carrying the plain history/identity ask, zero further attempts, and no lock left behind. The 80-rejection churn becomes this epic's permanent regression evidence, per the house rule that a real failure is closed by a reproduction, not a plausible patch.

_Advances: failed transactions clean up after themselves, dead locks are named instead of feared, and the incident that motivated the epic can never quietly return._

## Acceptance Criteria

- [ ] Lock tests: every failure path releases the lock; a stale lock (dead holder) is detected, named in the operator-facing reason, and recovered; a live holder is never stolen.
- [ ] Discovery tests: the prior-completion-key lookup on a repo with no commits returns `Ok(None)` and the transaction proceeds to its real precondition failure (or success), never a fatal exit-128; a repo whose history contains the key still short-circuits idempotently.
- [ ] The field-replay regression runs in CI: unborn-branch, identity-less environment → one bounded retry sequence, one park with the plain history/identity ask, no residual lock; the test cites the preserved journal as its source.
