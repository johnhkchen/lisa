# E-032: Informative pane lifecycle names

## Intent

Make the four coding panes in a lisa loop understandable at a glance. Pane
titles should come from lisa's scheduler state instead of whatever foreground
process happens to set them, and the same naming contract should apply to
Claude and Codex.

Today Claude panes inherit a fragment of the initial prompt, such as
`Complete T-029-01 workflow phases through review`, while Codex panes often show
only `lisa`. Neither reliably tells the operator which ticket is assigned, what
the ticket is about, which agent is running it, or whether the pane is available
for reuse.

## Experience contract

- An assigned pane identifies the actual working agent, ticket ID, and ticket
  title from frontmatter.
- A released pane is visibly idle and, when a resident provider session remains,
  identifies that provider.
- Fresh launch, same-provider reuse, and cross-provider replacement produce the
  same title format.
- Pane titles never claim a ticket is idle or complete before lisa has completed
  the corresponding scheduler transition.
- Names remain concise and safe for Zellij even when ticket titles are long or
  malformed.

## Story

- **S-032-01 — Informative pane lifecycle names:** own Zellij pane titles from
  assignment through release for both Claude and Codex.
