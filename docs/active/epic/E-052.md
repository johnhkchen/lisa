## Intent — the bigger-picture play

Recent Activity is the operator's newspaper: the one surface that should compress a morning of scheduler work into ten honest lines. The 0.4.4 field run showed seven visible lines carrying two facts. "Skipping T-002-01-02: thread already exists" appeared four times, because the scheduler logs its own no-op on every scheduling pass and a pass runs on nearly every event. "T-002-01-02 completed Design" appeared twice, because one phase transition emits two events that both project to "completed" lines — entering a phase prints the same sentence leaving it will print, so consecutive transitions stutter, and a transition observed by two of the three advance detectors doubles the pair. And every line was stamped `495696h 11m`, which is less a clock malfunction than a confession: entries carry no timestamp at all — the UI conversion hardcodes zero, so the "ago" arithmetic faithfully renders seconds-since-1970.

Three defects, one theme: the feed reports lisa's inner loop, not the operator's news. This epic makes the feed answer the two questions a person supervising panes actually asks — what changed, and how long ago — and nothing else. A healthy in-flight thread stops re-announcing itself every pass. One fact becomes one line, and a fact that genuinely recurs folds into itself with an (x3) tag instead of scrolling real news off the top of a 100-entry ring.

## Value to the design

Advances P2 — a timestamp reading half a century is a state label that does not correspond to reality, the same species of lie as a green gate that CI bounces; after this epic every stamp is a true age and every line is a distinct fact. Advances P4 — the feed becomes glanceable: an operator returning from lunch reads five lines and knows what moved, without mentally deduplicating scheduler chatter.

## Done looks like

The loop runs over lunch. The operator comes back and glances at the feed: "T-016-01-01 completed Design — 3m ago", a commit sweep at "20m ago", a warning that fired three times folded into one line tagged (x3) wearing its latest age. No skip chatter anywhere — though the skip decisions still show up in the Shift+D state dump when someone debugging wants them. Five minutes later the same lines read 8m and 25m: ages tick on the existing five-second render cadence with no new machinery.

## Context & constraints

Grounds against crates/lisa-plugin/src/lib.rs — `log_activity` (~3327) pushes a bare `ActivityEvent` (no time field in any variant, crates/lisa-core/src/types.rs ~976); the UI conversion hardcodes `Duration::ZERO` (~9066) while `current_time` is real wall-clock (~8973); the noise emitters are the skip Info inside `schedule_ready_tickets` (~4934) and the dual `PhaseCompleted`/`TicketPhaseChanged` pairs at the three advance detectors (~5548, ~6086, ~6192, ~3115), both variants projecting to "completed" lines (~9080–9091); the ring cap is `MAX_ACTIVITY_LOG = 100` (~960). Rendering grounds against crates/lisa-plugin/src/ui.rs — `ActivityEntry.timestamp` already exists (~299), `format_time_since`/`format_duration` (~1009, ~429). The refresh cadence is already paid for: the timer event always re-renders (~8637, five-second poll), so true ages tick for free once entries carry them.

Sequencing: timestamps land first — folding bumps a "latest occurrence" stamp, which must exist before it can mean anything. Demotion must not become erasure: the Shift+D dump's only event record is today this same ring (`format_snapshot`, ~8098), so a demoted skip gets its own berth there — decisions stay visible and recoverable (P2). NON-GOALS honored: N4 — no logging framework, no severity system, no config surface rides along; the log stays a capped Vec and each fix is measured in tens of lines. This epic heads the 0.4.5 UI train: every ticket in E-052/E-053/E-054 edits the same two files (lib.rs, ui.rs), so per the workflow's concurrency rule the train runs as one chain — pulling a later epic forward means consciously cutting its cross-epic edge.

Decomposition artifact rule: children spell the constraints plainly — every claimed "one line" outcome carries a unit test counting entries; the epoch-zero shape that produced 495696h is pinned as a negative fixture rendering a bounded fallback; demoted chatter is shown surviving in the state dump.
