## Intent — the bigger-picture play

The 2026-07-16 landing-probe pair (docs/knowledge/landing-probes/) established a clean split: an agent that merely *read* Lisa's surface concluded it was a ticket-graph tool, while an agent that *lived inside* a `lisa loop` session put "Claude Code agents, concurrently" in its headline — but **neither could state the benefit**. "You don't babysit this; nothing needed your approval; here's the audit trail" appears nowhere an agent can quote, so no probe page has ever said it. Experience teaches what happens; only written words teach why you'd want it. The play: make the running experience quotable. The context Lisa injects into every agent session (the workflow preamble and assignment framing in crates/lisa-cli/src/templates.rs) carries the benefit-first purpose paragraph — reusing S-046-07's sentence, not re-inventing it — and the run narrates its own win at the end: a post-run summary stating how many tickets completed, that zero manual approvals were requested, and where the evidence lives (.lisa/provenance.jsonl, the completion journal, per-ticket work docs). Then the landing-probe series (the standing "have your favorite agent make a landing page for lisa" tutorial experience) becomes the regression instrument: future probe pages must flip the rubric's Benefit and Evidence columns to yes.

## Value to the design

Advances P4 — the run explains itself: an operator (or the agent summarizing to them) sees ownership, zero-approval completion, and the evidence trail stated in plain language at the moment it matters, not reverse-engineered from terminal contents. Advances P5 — the probe series turns "did the point come through" into a scored, repeatable field measurement with archived artifacts, so copy regressions are caught the same way scheduler regressions are.

## Done looks like

On the 0.4.1-rc surface: a fresh landing probe (either method — direct tour or loop-built) produces a page that names the coding agents, states the no-babysitting benefit, and points at the evidence trail unprompted — rubric columns 1–3 yes, purpose before mechanism. The post-run summary after a completed loop reads like a sentence a nontechnical person would understand and repeat, with real counts and real ledger paths. Injected session context opens with the purpose paragraph, byte-consistent with the S-046-07 copy.
