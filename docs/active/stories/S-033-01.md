**Scope:** The recycled-Codex ownership transition in `crates/lisa-plugin/src/lib.rs` plus the adapter/hook boundary where needed for the `/clear` -> cleared-hook -> prompt -> delayed-Enter path. Introduces a recycled-seat assignment state (`assigned-pending-ack` distinct from `owned`, plus `recovering`), a Codex-appropriate ticket-scoped acknowledgment, ack-gated ownership, and a bounded wait that ends in a fresh-session fallback. Does not change the Claude handoff contract or `ui.rs` rendering.

**Story acceptance:** In scheduler unit tests, a recycled Codex seat handed a new ticket enters `assigned-pending-ack` and is never reported `owned` until the Codex ack detector fires; with ack withheld, the bounded deadline moves the seat to `recovering` and spawns a fresh Codex session for the same ticket — no silent stall, no owned-without-ack. Claude's transition path is unchanged across the same tests.

**Honest boundary:** The state machine and acknowledgment classifier are fixture-proven and FREE, with no live tokens. The live consecutive-reuse proof lives in S-033-03 and is explicitly isolated behind the deterministic regression ticket rather than hidden inside the implementation tickets.
