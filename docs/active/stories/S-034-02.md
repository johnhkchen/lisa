**Scope:** The five authority surfaces that must be checked against the ticket's current lease: Codex acknowledgement promotion (`lisa-plugin/src/codex_ack.rs` and its scheduler consumer), liveness/heartbeat, artifact admission from the shared work tree, completion gating into `commit_transaction::complete_ticket`, and provenance. Each surface reads the lease store from S-034-01 and rejects stale prior-attempt activity scheduler-side. Artifact existence alone is not attribution; use attempt-scoped staging/publication or an equivalently enforceable boundary.

**Story acceptance:** With a ticket whose current lease is generation N, tests feed prior-attempt (generation N-1) acknowledgement, heartbeat, artifact output, completion, and outcome events. Every stale event/output is rejected: the replacement is not promoted to Owned, kept alive, credited, advanced, or completed from old activity. Current-lease activity is accepted. Attempt-level timeout/fence history remains reconstructable, while exactly one attempt can publish authoritative `done` provenance.

**Honest boundary:** Rejection reuses E-033's `LISA_ASSIGNMENT` generation marker as the attempt transport — no second handshake or recovery path. Hook changes are allowed only where needed to carry authoritative attempt identity; terminal-text inference is not. Fixture-proven and free; the live split-brain proof is S-034-03.
