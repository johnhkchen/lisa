**Scope:** lisa-core gets an `AttemptLease` type (ticket id + monotonic attempt/generation, building on the generation already seeded in `codex_ack.rs`) plus a validation helper, likely in `types.rs` beside `Thread`. In `lisa-plugin/src/lib.rs` this owns the dispatch and timeout seams. It mints the lease and installs the revoke-and-fence-before-reschedule boundary. It does not touch the per-surface rejection paths (ack/liveness/artifact admission/completion) — those are S-034-02.

**Story acceptance:** A scheduler unit test proves that when a running thread hits hard-silence timeout, the prior attempt's lease is revoked and its pane fenced (terminated/disqualified) BEFORE release_slot_for_ticket makes the ticket reschedulable, and a freshly dispatched attempt for the same ticket carries a strictly higher attempt id than the fenced one; fencing terminates in a named, bounded state (no infinite retry, N2 — Infinite retries or silent babysitting).

**Honest boundary:** Establishes the lease and fence at the mint/timeout boundary only; it does not yet reject stale activity at the individual surfaces (S-034-02) or prove the live split-brain (S-034-03). Everything is fixture-proven and free. E-031's commit transaction and E-033's acknowledgement handshake are consumed as prerequisites, not rebuilt.
