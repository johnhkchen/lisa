**Scope:** The 2026-07-16 tour probe (gpt-5.4-mini on the v0.3.0 fixture — evidence in T-046-06-02's work dir) proved the installed surface teaches mechanism, not purpose: a faithful, fabrication-free agent-written landing page led with "Lisa turns tickets into a schedulable DAG" and never once said "coding agent." **Story acceptance:** String-level tests assert that on each surface the purpose sentence (naming coding agents) appears before any mechanism vocabulary, and that generated CLAUDE.md/AGENTS.md carry the purpose paragraph. All copy follows the brand voice: plain kitchen-table English, verb-forward, no jargon a visitor wouldn't say aloud. Field acceptance rides the closing run (T-046-06-03): the tour-probe rematch on the fixed surface must produce a page that names coding agents and the don't-babysit purpose unprompted.

**Honest boundary:** Copy only — no behavior changes, no new commands, no new provenance features (one sentence of discoverability, pointing at what already exists). Agent comprehension cannot be unit-tested; the closing-run tour rematch owns that judgment. E-044 stays its own epic — this story changes words on surfaces E-044 already structured, and its locked help-surface regression tests may be updated for wording only, never structure.
