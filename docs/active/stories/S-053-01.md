**Scope:** Make [d] a working signature. (1) **The override path.** Today `dispatch_completion_at`'s operator guard (lib.rs ~2422) asks `passing_review_disposition` (~1944) and returns false on Block or Invalid — and the fail-closed parser makes missing/malformed files Invalid too (disposition.rs ~103) — so the tickets in the attention box are precisely the ones [d] cannot touch. Add an operator-note branch: when the operator selects a canned disposition, dispatch carries an operator-authored `DispositionNote` as the completion note and rides the untouched sealing path (`finish_successful_completion` ~3109: Done, `rebuild_dag` unblocks dependents, provenance note, seat release). The catalog is small and speaks product: on a Block, roughly "the evidence already satisfies this — the review read it too strictly", "this can't be verified from this machine — accepted as far as it can check", "this is beyond what the ticket can reach — accepted as-is"; on a missing/invalid disposition, a reason that says plainly no agent review is on file. Citations stay real per S-049-06 (the block's own disposition, review.md, progress.md) — and for the fail-closed shapes, where there is no block to quote, the note's fields are defined rather than invented: the quote records the state being overridden, the citation the path the operator inspected, the summary the canned reason. Research enumerates the catalog against the 0.4.4 field cases. (2) **The modal becomes a two-step choice.** The MarkDone modal (navigation and confirm/dismiss only — arrows and their j/k aliases, Enter, Esc/q; lib.rs ~8150–8182) gains a reason step after ticket selection — the block's ask displayed above the choices, a recommended default preselected, Esc backing out cleanly. No free-text input anywhere.

**Story acceptance:** A ticket parked on a Block seals via [d] + Enter-on-reason; its dependents go ready on the next scheduling pass; ledger and journal record operator authority, the chosen reason, and the overridden ask; the note appears in Notes-for-you. The same flow works on a ticket with no disposition file. A path with no reason selected still refuses to seal — demonstrated red, kept as a fixture.

**Honest boundary:** No parallel completion machinery (N4) — one new authority branch feeding the existing path. No quality-hedge reasons in the catalog; "the work looks wrong" has no signature, only send-back (S-049-06 discipline). No free text: choices, not essays.
