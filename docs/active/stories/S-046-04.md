**Scope:** Every string an agent can read converges on the one blessed path. Docs sweep: README puts the single-command install as the first code block with an explicit "you do not need Rust to use Lisa — agents: do not build from source" note and a clear use-Lisa vs develop-Lisa split; repo CLAUDE.md and AGENTS.md open with the same note before any cargo command; the stale docs/knowledge/lisa-loop-setup-guide.md (obsolete `wasm32-wasi` target, manual layout instructions, `lisa init` described as future) is deleted or reduced to a tombstone pointing at the README. Strings sweep: doctor's missing-Zellij hint stops leading with `cargo install zellij` and points at the managed runtime / prebuilt binaries; the `lisa loop` embedded-WASM error stops recommending `git clone … && just release` and names the shell installer; doctor gains the two missing checks — `git` present (with an apt hint) and embedded WASM non-empty (catching the build.rs placeholder trap that today passes doctor and dies at loop).

**Story acceptance:** `rg 'cargo install zellij'` over the repo returns nothing; the stale guide is gone or tombstoned; README's first code block is the installer one-liner; CLAUDE.md/AGENTS.md lead with the users-don't-build note. Doctor with `git` absent from PATH names the gap and the apt remedy; a binary built with the empty placeholder WASM fails doctor with a named message instead of passing. Error-string assertions live in tests where the strings are produced, so regressions are caught mechanically.

**Honest boundary:** All user-facing copy follows the brand voice — plain kitchen-table English, verb-forward, no jargon. Whether an *agent* actually follows the improved strings cannot be unit-tested; that judgment belongs to the Chromebook test (S-046-06), including its seeded-failure variants. Remedy wording that references the managed runtime should land after or alongside S-046-02 so it never advertises a mode that doesn't exist yet.
