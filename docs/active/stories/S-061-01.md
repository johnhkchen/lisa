**Scope:** The signal hooks resolve their signal directory as a relative path:

```sh
# .lisa/hooks/on-ack.sh, on-heartbeat.sh, on-stop.sh
SIGNAL_DIR=".lisa/signals"
```

So an agent in a Lisa-managed pane writes its liveness into **whatever repository
it happens to be standing in**, not the one its pane was leased from. The hooks
already know the pane — they are guarded on `$LISA_PANE_ID` — but not the
project.

Measured on this desk, 2026-08-11:

```
loop                  lisa loop --path ~/swe/repos/steer   (pid 80971, alive)
its agent's pane      LISA_PANE_ID=1
the ticket it held    "run `steer brief` on a real run — either desk"
where it ran          ~/swe/repos/screen-design
what got written      ~/swe/repos/screen-design/.lisa/signals/pane-1.ack
                      ~/swe/repos/screen-design/.lisa/signals/pane-1.stopped
```

The payload confirms it: `cwd: /Users/johnchen/swe/repos/screen-design`, and the
prompt inside is the other project's brief-rewrite call.

**What it cost.** `screen-design` had five ready tickets, no loop, every zellij
session `EXITED`, `0 in progress`, and all four of its leases on `done` tickets.
Its status strip refused to start a run anyway — correctly, on the evidence it
had — because a signal file in that repository had been written seconds earlier
by an agent belonging to a different project. The operator pressed the launcher,
got a refusal, and asked why another repository's loop was interfering.

**Why it gets worse.** Nothing here was misused. The agent read another
repository, which is ordinary and which that desk's own contract encourages;
`.lisa/signals/` is documented as single-consumer and nobody else touched it. A
desk that runs two projects at once produces this by doing the normal thing, and
the failure is silent in both directions — the true project loses nothing
visible, and the innocent project gains a seat nobody can point at.

**Non-goals.** Not a change to what the signals mean or who consumes them. Not a
request to stop agents reading other repositories — that is the useful behaviour
this happens to break.
