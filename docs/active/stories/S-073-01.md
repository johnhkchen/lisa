**Scope:** A lisa loop's entire output is commits. It spends an hour of a model's
attention producing them and then needs a road to land them on — and lisa checks
everything about a run except that.

`lisa doctor` is thorough. It checks the binary, zellij, git's presence, the
agent CLI, the unattended confirmation, the WASM plugin, the project version,
the completion seal, the pane routes, and even *the environment agents will start
in*, down to naming the seven inherited variables it drops. It does not check
whether a commit made in that pane can reach the remote.

On 2026-08-15 the desk measured what that costs. From a shell with no agent and
no keychain — which is the shell an overnight run actually has:

```
laptop   gh token in the KEYCHAIN   git-over-https ✗    git-over-ssh ✓
mini     gh token in a FILE         git-over-https ✓    git-over-ssh ✗
```

**Each machine can land work only by the road the other cannot use**, and neither
line was chosen — each is wherever the tool that set that machine up happened to
put its secret. This week the operator moved 98 commits by hand through a
GUI-side pane because the session that made them could not push.

## Why this is lisa's problem and not only the desk's

The desk half is filed as `screen-design` `T-030-07`/`T-030-09` — one road, chosen,
working on every machine. That is the fix. This story is what lisa should do
**while that is not yet true, and after it is true and quietly breaks.**

Lisa is the thing that knows a run is about to start, knows which repository it
is in, and already has a place to say *this board is not ready*. It is the last
honest moment before an hour is spent. Nothing else on the desk is standing
there.

## What this story does not change

Not the seal. `commit-sealed` — finished work lands as history — is right, and a
board that cannot push should not be talked into a weaker seal to get past this
check. **The answer to an unlandable board is to say so, not to lower the bar for
done.**

Nor does lisa acquire credentials, hold them, or repair them. It reads what the
shell it is in can already do. `S-030`'s rule that nothing installs a credential
is the desk's, and lisa is inside its walls.
