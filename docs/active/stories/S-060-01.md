**Scope:** When a run dies without shutting down — the machine swaps, the
terminal is killed, the plugin goes with it — the pane lease markers it wrote
into `.lisa/signals/` stay on disk. `lisa status --json` keeps reporting them in
`attempts[]` as seats that are neither `superseded` nor on a `done` ticket, which
is the documented definition of a seat that is working. Nothing removes them.
`lisa clean` does not: it lists finished attempt folders and explicitly leaves
signals alone.

Measured on `screen-design`, 2026-08-10, after a run died at 17:45:

```
.lisa/signals/pane-0.lease  {"ticket_id":"T-008-08","attempt_id":1}   done
.lisa/signals/pane-1.lease  {"ticket_id":"T-009-05","attempt_id":1}   implement
.lisa/signals/pane-2.lease  {"ticket_id":"T-008-06","attempt_id":1}   review
.lisa/signals/pane-3.lease  {"ticket_id":"T-008-07","attempt_id":1}   done
```

Every zellij session on the machine reported `EXITED`. No process held anything.
`lisa status` reported `2 in progress` for a board where nothing was running.

**Why it matters beyond a stale number.** `json-guide` tells a consumer that an
entry which is neither superseded nor done is *"Lisa's best answer to 'this seat
is working'"*, and consumers believe it. A status strip on the same desk reads
`attempts[]` to decide whether starting a run would create a second loop, and
correctly refused to start one for the rest of the day. The operator's only way
out was to run `lisa loop` by hand, which reassigns the tickets and rewrites the
leases — so the state clears, but only by doing the thing the state was
preventing.

Running `lisa loop` again is a fine recovery and it is not a discoverable one.
Nothing in `lisa status`, `lisa clean` or `lisa doctor` says that two seats are
held by a run that no longer exists, or what to do about it.

**Non-goals.** Not a request to change the signal contract, which is right as it
is: the plugin owns those files and consumers were told not to read them
directly. This is about what happens when the process that would have cleaned up
is the one that died.
