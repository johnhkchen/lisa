**Scope:** A board runs four panes and they are not doing the same kind of work.
One is planning, one is grinding through a mechanical rename, one is reviewing.
Today they all run whatever `[agent].model` says, which is **one value for the
whole board**, and none of them can be told how hard to think.

The operator, 2026-08-15:

> *"I'd like to have tickets appropriate for Sonnet 5 Medium Effort being run on
> both the mac mini and laptop as we're at the last 35% of our weekly usage and
> it's halfway through the week only. Overseers and planners can be opus."*

That is a per-pane decision and there is no per-pane place to put it.

## The good news is that both halves already exist

**The client takes both words.** `claude --help`, on the version this desk runs:

```
--model <model>    Model for the current session
--effort <level>   Effort level for the current session
```

So this needs **no keystroke injection**. That was the operator's suspicion —
*"we might have to do a bit of pane keystroke injection if the CLI doesn't
handle it well"* — and the answer is no: it is a flag, and lisa already builds
an argv.

**lisa already carries a model.** `[agent].model` exists, defaults to `"opus"`,
and `codex_args` shows the argv-passing pattern is established. What is missing
is not the mechanism; it is that there is exactly one of it.

**And lisa already measures what this will spend.** `capture_usage.rs` writes
`.lisa/<client>/captures.jsonl` per pane, from the Stop hook, with
`input_tokens` and `output_tokens`. That is the ledger this story makes
interesting — and the reason `T-071-01-02` exists.

## What must not happen

**Do not overwrite the operator's own defaults.** In their words: *"Don't
overwrite claude code's defaults, allow per-pane adjustment of model and
effort."* A pane that is told nothing must run exactly what a person typing
`claude` in that directory would get. `[agent].model`'s own description already
holds this line — *"Omit it to use whatever the agent runs by default"* — and
per-pane settings must inherit that restraint rather than quietly establishing a
new floor.

**Codex is not an afterthought.** *"prepare to support the same for codex."*
`agent.client` already chooses between them and `codex_args` already exists, so
the shape here should be one that codex can wear rather than a claude-shaped
hole that gets widened later.

## Not in scope

Not deciding *which* pane gets which model — that is the operator's call and a
config question. Not the weekly budget: `S-072-01` is where running out of it
lives, and this story is the lever that story will need to pull.
