## Context

When a Claude session completes a phase, it writes an artifact (e.g. `research.md`)
to `docs/active/work/{ticket_id}/`. Lisa should detect this and advance the ticket.

## Acceptance Criteria

- `handle_filesystem_update()` scans each active ticket's work dir for new phase artifacts
- Artifact filenames mapped to phases via `Phase::artifact_filename()` (research.md → research done → advance to design)
- `ticket::update_ticket_phase()` called to update YAML frontmatter
- `ActivityEvent::PhaseCompleted` and `ActivityEvent::TicketPhaseChanged` logged
- If new phase is `review`, thread is parked
