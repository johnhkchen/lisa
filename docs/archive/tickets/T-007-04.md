## Context

Not everyone has Rust installed. For broad adoption, prebuilt binaries for common
platforms should be downloadable from GitHub releases. The CLI binary is
self-contained (WASM plugin embedded), so a single binary per platform is all that's
needed.

## Objective

Add a GitHub Actions release workflow that builds and publishes prebuilt binaries
when a version tag is pushed. Users should be able to download and run lisa without
any build tools.

## Acceptance Criteria

- [ ] `.github/workflows/release.yml` workflow triggered on `v*` tags
- [ ] Builds binaries for: x86_64-linux, aarch64-linux, x86_64-macos, aarch64-macos
- [ ] Build matrix: compile WASM plugin first, then build CLI with embedded WASM
- [ ] Binaries are stripped and compressed
- [ ] GitHub release created automatically with binaries attached
- [ ] Release notes include the tag message or auto-generated changelog
- [ ] Versioning: workspace Cargo.toml version matches git tag
- [ ] Installation instructions in README updated with download links / curl one-liner
- [ ] CI workflow (non-release) runs `cargo test --workspace` and WASM check on PRs
