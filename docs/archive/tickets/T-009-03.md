## External Project Dogfood

### Goal

Run the full `lisa init` → `lisa validate` → `lisa loop` pipeline on a real
external project (not lisa). This is the first-user experience test.

### Test Plan

1. **`lisa init`** on the target project
   - Verify generated CLAUDE.md makes sense for the project
   - Verify rdspi-workflow.md is placed correctly
   - Verify idle hook config is generated

2. **LLM setup verification** — Have a Claude Code session review the
   generated files and confirm they're correct for the project. Fix any
   issues surfaced.

3. **Write tickets** — Create 2-3 tickets for real work on the project,
   with at least one dependency edge.

4. **`lisa validate`** — Confirm tickets parse, DAG is valid, no errors.

5. **`lisa loop --dry-run`** — Verify execution order and layout look right.

6. **`lisa loop`** — Run for real. Observe:
   - Agent sessions start and work through RDSPI phases
   - Phase transitions fire (artifact detection + idle signals)
   - Implement → Review advances via idle signal
   - Dashboard renders correctly
   - No crashes or confusing error messages

7. **Document issues** — Any problems found become candidates for a
   follow-up sprint.

### Acceptance Criteria

- At least one ticket completes Research through Review without manual
  phase intervention on the external project
- No crashes during the full run
- Issues documented for follow-up
