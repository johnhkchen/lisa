## Context

The scheduler spawns Claude Code sessions by writing commands to zellij terminal
panes. The exact command string determines whether the agent gets the right context:
CLAUDE.md path, ticket file, work directory, RDSPI workflow. If any part of the
command is wrong, the agent session starts but works incorrectly — and there's no way
to see what was sent.

## Objective

Log the full session launch command for each spawned agent session, and verify that
the command includes all required context elements. Add a structured representation
of the launch command so it can be inspected and tested.

## Acceptance Criteria

- [ ] When a session is spawned, log an `Info` event with the full command string
- [ ] Command includes: `claude` invocation, `--print` or appropriate flags, ticket file path, work directory path
- [ ] RDSPI workflow reference is included in the session context
- [ ] CLAUDE.md path is resolvable from the WASI sandbox (prefixed with /host/ correctly)
- [ ] Log the pane_id assigned to the session
- [ ] Add a `SessionLaunch { ticket_id, pane_id, command }` variant to ActivityEvent for structured capture
- [ ] Tests verifying command construction for various ticket configurations
- [ ] Tests verifying /host/ prefix handling for WASI paths
