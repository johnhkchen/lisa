## Dogfood: Idle Signal Phase Transitions

### Goal

Run `lisa loop` on a small test project (or lisa itself) with the new idle
signal hooks active. Verify that phase transitions happen automatically
without manual intervention.

### Test Plan

1. Create a 2-ticket test project with one dependency
2. Run `lisa init` — verify hook config and signal script are generated
3. Run `lisa loop` — observe:
   - Agent sessions start and work through RDSPI phases
   - Idle signals fire when agents finish work
   - Research → Design → Structure → Plan transitions happen via
     artifact detection (existing) or idle + artifact (new)
   - **Implement → Review transitions happen via idle signal alone**
   - Review → Done still requires manual 'd' press (expected)
4. Document any issues found for follow-up

### Acceptance Criteria

- At least one ticket completes Research through Review without manual
  phase intervention
- Implement → Review specifically advances via idle signal
- No regressions in existing phase detection
