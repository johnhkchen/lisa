## Execution Order

```
1. lisa init --dry-run     (observe plan)
2. lisa init               (create missing hooks, update settings.local.json)
3. Manual fix on-idle.sh   (LISA_TICKET_ID → LISA_PANE_ID)
4. lisa validate --check-tools  (confirm green)
5. just build-cli          (rebuild with latest code)
6. Create test tickets     (T-TEST-01, 02, 03)
7. lisa loop --dry-run     (verify DAG and layout)
8. lisa loop --max-threads 1  (live run)
9. Observe and document    (progress.md)
10. Cleanup test tickets   (remove T-TEST-* files)
```
