## Distribution & Onboarding

Running lisa on a new project should be as simple as any other CLI tool: install it,
run a command, and go. Today the onboarding path requires reading a 450-line setup
guide, manually creating files, and knowing the ticket format by heart. The CLI
exists but it doesn't guide you.

This sprint adds two things: a `lisa setup-guide` command that outputs LLM-friendly
instructions so a Claude Code session can set up a project autonomously, and
packaging so the CLI can be installed with a single command. The existing
`lisa validate` is enhanced to cover full pre-loop readiness so `setup-guide` has a
clear "you're done" signal.

**Track A — Onboarding** (T-007-01 → T-007-02): `setup-guide` command that detects
the project and outputs contextual setup instructions, then enhance `validate` into
a comprehensive pre-loop readiness check.

**Track B — Packaging** (T-007-03 → T-007-04): Publish to crates.io for
`cargo install`, then add GitHub release workflow for prebuilt binaries.

DAG for 2-agent concurrency:
```
Wave 1: T-007-01 + T-007-03  (independent, parallel)
Wave 2: T-007-02 + T-007-04  (both unblocked after wave 1)
```
