## Configuration and Validation

Add project-level configuration file support (.lisa.toml) with comprehensive validation:
- Parse and load .lisa.toml at plugin startup
- Support configurable project settings (max_threads, ticket directories, auto-advance rules)
- Validate configuration values and reject invalid settings with clear error messages
- Provide sensible defaults when no config file exists
- Surface validation errors in the dashboard
