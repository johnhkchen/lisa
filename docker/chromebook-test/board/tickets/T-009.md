## Context

Polish pass on the page built in T-008: confirm it works for a non-technical
visitor on a phone (the likely device for a first-time, casual visit) and
meets basic accessibility expectations, since a page targeted at newcomers
should not silently exclude anyone. This review also holds the design bar:
T-008 promises a page that looks deliberately designed, and a
browser-default-looking page does not clear this review — send it back with
specifics rather than waving it through. Polish you add here (refined
spacing, better contrast, smoother interactions) should raise the design,
not flatten it.

## Acceptance Criteria

- Page is legible and usable at common mobile viewport widths (no
  horizontal scrolling, tap targets sized appropriately, hero/CTA still
  visible near the top on mobile).
- The T-008 design bar holds after this pass: cohesive palette tokens, type
  scale, spacing rhythm, a distinct hero, and styled hover/focus states are
  all present and coherently used — a page that could be mistaken for
  unstyled HTML fails this review.
- The hero's centerpiece visual is present and wordless, animates smoothly
  without ever blocking or crowding the hero copy and CTA, and reduces to
  its static state under `prefers-reduced-motion`.
- Images/icons (if any) have descriptive alt text; heading levels are
  sequential and describe document structure, not just visual size.
- Color contrast for body text and CTA meets WCAG AA at minimum.
- Page is checked with a keyboard-only pass: every interactive element
  (links, CTA, FAQ toggles if any) is reachable and usable via keyboard
  alone.
