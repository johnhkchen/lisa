## Context

Polish pass on the page built in T-008: confirm it works for a non-technical
visitor on a phone (the likely device for a first-time, casual visit) and
meets basic accessibility expectations, since a page targeted at newcomers
should not silently exclude anyone.

## Acceptance Criteria

- Page is legible and usable at common mobile viewport widths (no
  horizontal scrolling, tap targets sized appropriately, hero/CTA still
  visible near the top on mobile).
- Images/icons (if any) have descriptive alt text; heading levels are
  sequential and describe document structure, not just visual size.
- Color contrast for body text and CTA meets WCAG AA at minimum.
- Page is checked with a keyboard-only pass: every interactive element
  (links, CTA, FAQ toggles if any) is reachable and usable via keyboard
  alone.
