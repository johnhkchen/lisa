## Context

Write the copy for the hero section: the first thing a brand-new,
non-technical visitor sees. This is the highest-leverage copy on the page —
per T-002's bottom-line message and T-003's outline, it must state the value
proposition in one glance, with no jargon, and a single clear call to
action.

## Acceptance Criteria

- Hero headline states the T-002 bottom-line message in plain language, no
  unexplained jargon (no "DAG," "seal," "ticket board" without a plain-
  language gloss, etc.).
- A one- to two-sentence subheadline gives the visitor one concrete reason
  to believe the headline (drawn from T-002's supporting reasons).
- Exactly one primary call to action is defined, with the exact button/link
  text and where it should point (e.g., quick start, install instructions,
  or a later section anchor) — reviewed against what a first-time,
  non-technical visitor is actually ready to do.
- Copy is reviewed against T-003's outline to confirm it does not duplicate
  or preempt content owned by T-005, T-006, or T-007.
